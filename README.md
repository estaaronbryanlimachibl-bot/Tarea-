Ingresar el saldo inicial.
Seleccionar una opción del menú de productos.
El programa verificará si existe saldo suficiente para realizar la compra.
Si la compra es válida, se descontará el precio del producto del saldo disponible.
El usuario podrá seguir comprando hasta que decida salir o no tenga saldo suficiente.
Al finalizar se mostrará:
Cantidad total de productos comprados.
Saldo restante.
